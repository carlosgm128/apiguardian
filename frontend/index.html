API Guardian

AI agents that catch breaking API changes before your clients do.

API Guardian compares two versions of an API's documentation (OpenAPI 3.x, Swagger 2.0 or Markdown) and reports what changed, how it changed, and what could fail for clients built against the older version.

Features

  • A deterministic diff first: severity is judged from the client's side, so stricter requests and looser responses count as breaking.
  • One AI worker agent per changed endpoint, and a lead agent that ranks what could fail, on Claude or local Ollama models.
  • Live API tracking: every new version of a spec URL is snapshotted and reported, with a monitoring dashboard for scheduled checks.
  • Impact per application, with notifications to Slack, Microsoft Teams, Discord, webhooks, GitHub and GitLab pipelines.
  • Reruns with a different model, multi-GPU agent placement, and full inference observability.
